# Thesis italic fonts

Atkinson Hyperlegible Italic and Bold Italic complement the existing body font so
Harvard references retain italic publication titles in the PDF. These two files
come from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible
- https://raw.githubusercontent.com/google/fonts/main/ofl/atkinsonhyperlegible/AtkinsonHyperlegible-Italic.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/atkinsonhyperlegible/AtkinsonHyperlegible-BoldItalic.ttf

Retrieved 23 October 2026. The accompanying `OFL.txt` contains the SIL Open Font
License. These document assets do not change the desktop runtime font inventory.
