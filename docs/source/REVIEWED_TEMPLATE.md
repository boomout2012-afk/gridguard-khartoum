# Reviewed thesis template

`reviewed-thesis-template.docx` is the unchanged Word thesis supplied by the authors
with the committee review. It is preserved as a historical source and layout template,
not as the current submission. Its SHA-256 is
`d6f5cef5d56bdcb7f6c78989d68f8c586ba9b9289ecf5b765ebd34a8e26d3d59`.

The editable revised thesis is generated by `tools/build_focused_thesis_docx.py` from
the current PDF's resolved manuscript and build metadata. It retains the reference
cover and academic Word page system while updating the reviewed content, equations,
graphs, navigation and cross-references. The source template is never saved or modified.

Native equations are converted from MathJax MathML using the `MML2OMML.XSL` stylesheet
supplied with Microsoft Office. That proprietary stylesheet is located at build time
and is not included in this repository. Microsoft Word updates the document fields
and exports a PDF through `scripts/export-submission-thesis.ps1` for visual review.
Run that helper with PowerShell 7 (`pwsh`); Windows PowerShell 5.1 is not supported.
